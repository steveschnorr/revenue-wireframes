Design Language

A system for everything GTME ships. Dashboards, wireframes, vision docs, prototypes, and AI-generated artifacts — all speaking the same visual language.

One visual vocabulary for everything GTME ships.
i.
Why a design system

Every dashboard we've shipped invented its own visual vocabulary — colors, formatting, KPI tiles, loading states. The audit found:

This isn't a style guide. It's infrastructure. One set of tokens, one formatting library, one component vocabulary. The system makes the right choice the easy choice — for humans and for AI agents.

Faster

Templates and tokens beat blank pages. A new dashboard starts with the system, not from scratch. An agent generating a wireframe uses the same rules automatically.

More reliable

One green, one red, one date format. Pipeline Council's green (#639922) fails WCAG AA on white. The system's green (#1f7a4d) passes. That's the kind of thing you fix once.

Better

Source lines and "as of" timestamps are required, not optional. Every metric answers "where did this number come from?" before anyone asks.

ii.
Principles
1
Quiet chrome, loud data
Paper, rules, and labels are warm and recessive. Numbers are big and saturated. Contrast goes where the eye should go.
2
Oxblood marks authorship
The 2px rule and the eyebrow. That's it. Never touches status or data — red, amber, green handle that.
3
Mono means metadata
JetBrains Mono for source labels, timestamps, record IDs, section numbers. If it's provenance, it's mono.
4
White cards on warm paper
Depth from surface contrast, not shadows or borders. No drop shadows. No border on cards.
5
Color always paired
Red, amber, green always appears with a label, arrow, or icon. Never color alone — a red number without context is just a red number.

vi.
When to use what

The GTME system owns wireframes, KPI dashboards, and vision docs. Prototypes that ship in-app use the Justworks UI Kit — GTME adds the eyebrow for annotations only.

Prototypes
Justworks UI Kit, Oately, their colors. GTME eyebrow for annotations only.
Wireframes
Full GTME system. Mono labels, warm paper, white cards.
KPI dashboards
Full GTME system. Display numbers, bars, stat tiles, source lines.
Vision docs
Most editorial. Oxblood rules, strong hierarchy, mono metadata.
